# 花间 · 美甲预约系统

一套适配手机的美甲预约前台与店铺预约看板。当前可直接本地运行；不接云数据库时会把预约保存在当前浏览器，方便体验。正式经营请连接 Supabase，并完成后台身份验证与通知渠道配置。

线上演示：[花间美甲预约系统](https://nail-booking-system-nine.vercel.app/)（当前为演示模式，预约保存在本机浏览器）。

## 本地预览

直接运行：

```sh
python3 -m http.server 5173
```

浏览器访问 http://localhost:5173。无需安装依赖。无 Supabase 配置时，数据只存在本机浏览器。

## 上线部署（Vercel + Supabase）

1. 在 Supabase 创建项目，在 SQL Editor 执行 `supabase/migrations/001_initial_schema.sql`。
2. 在 Vercel 导入此 GitHub 仓库并保留仓库根目录。仓库中的 `vercel.json` 已配置构建命令和根目录静态输出。
3. 在 `config.js` 填入 `supabaseUrl` 和 `supabaseAnonKey`（Supabase 项目 Settings → API 可找到），再提交并部署。
4. 上线前必须补齐店铺管理员身份验证与后台访问策略。当前演示看板对能打开网页的人可见；Supabase RLS 已禁止匿名读取预约和更改状态，但前端上线前还需接入 Supabase Auth 并为店员增加受限策略。

## 当前能力

- 项目、技师、日期和时段选择
- 顾客姓名、手机和备注收集
- 预约冲突时段提示（基于已读到的预约数据）
- 待确认、确认、完成、取消状态的后台看板
- Supabase PostgreSQL 表结构、行级安全策略和服务目录初始数据
- 演示模式使用浏览器本地存储

## 上线前待店主确认

请替换店名、门店地址/营业时间、服务价格与时长、技师名单、可预约提前天数、取消规则、收款方式，以及通知渠道（短信/微信/邮件）。本项目尚未连接短信或微信通知；预约成功页会提示顾客等待店铺联系。生产环境请完成店员登录、服务器端时段冲突校验、隐私政策和备份设置。
